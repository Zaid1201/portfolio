MSc dissertation · Aug 202602

Adversarial security of locally deployed LLMs

Built a Python evaluation framework for five local language models across 17 attack categories, using 400 prompts under two conditions and 4,000 API calls.

PythonLM StudioSecurity evaluationOutput filtering
Approach & outcomes
  • Compared attack success rates, severity, refusal styles and partial compliance using quantitative and qualitative analysis.
  • Designed a tunable unigram/bigram output filter. The study reported 53–100% attack-success-rate reduction across tested conditions and an 8% false-positive rate on benign responses.
  • Validated the filter through live LM Studio API testing. Results describe this experimental benchmark, rather than a guarantee for other models or deployments.
